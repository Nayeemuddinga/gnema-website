# G-NeMa Search Console Tracking Playbook

## Weekly dashboard

Review the previous 28 days against the preceding 28 days, plus a 90-day view for trend context.

### Track
- Total clicks
- Total impressions
- Average CTR
- Average position
- Top queries
- Top landing pages
- New queries
- Queries with rising impressions
- Pages with rising impressions
- Queries ranking approximately positions 5–20
- High-impression / low-CTR opportunities
- Indexing coverage for priority URLs

## Priority clusters

1. Brand: G-NeMa, G-NeMa AI
2. Enterprise AI: enterprise AI, enterprise AI operating layer, AI agents, agent governance
3. Multi-Agent AI: multi-agent organization, multi-agent orchestration
4. Oracle Database AI: Oracle database AI, Oracle performance monitoring, Oracle optimization
5. Space AI: space mission autonomy, space domain awareness AI
6. Robotics AI: autonomous robotics AI, multi-robot orchestration
7. Cybersecurity: AI cybersecurity, critical infrastructure AI security
8. Defense AI: defense AI, mission assurance AI

## Decision rules

- Position 5–20 + rising impressions: improve the page and strengthen internal links.
- High impressions + CTR below the site's recent baseline: test title/description alignment.
- New query cluster: consider adding a dedicated section or article.
- Two pages competing for the same intent: review overlap and strengthen the preferred page.
- New page with little/no data: do not repeatedly request indexing; allow crawling and improve discovery.

## Monthly review

At days 30, 60 and 90, export or record query/page performance and compare:
- topic cluster growth
- product-page discovery
- organic entrances to product pages
- article-to-product paths
- emerging search language
- content gaps

## Ops integration

The existing G-NeMa Ops Bot continues to perform technical SEO auditing and ranking checks. This playbook defines the human/strategy layer for interpreting Search Console performance and choosing the next content or optimization action.
